## ⚡ Quick Daily Log Helper

You can quickly record and push your daily progress with the built-in script:

```bash
# Basic usage (interactive prompt)
python log.py

# Or pass your summary directly
python log.py "Solved 2 LeetCode problems and worked on authentication API"
```

The script will automatically:
1. Create a formatted markdown log for today inside `logs/`.
2. Update the README log index.
3. Stage, commit, and push directly to GitHub to keep your streak glowing!
